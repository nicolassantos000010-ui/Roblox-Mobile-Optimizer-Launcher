# Roblox Mobile Optimizer Launcher

Um launcher para Roblox no Android/iOS focado em otimização usando FFlags.

## Recursos
- Modificação de FFlags
- Perfis de otimização (FPS Boost, Low Graphics, etc.)
- Lançamento direto do Roblox com configurações salvas
- Interface simples para mobile

## Estrutura do Projeto

- `fflags/` : Configurações JSON de FFlags
- `scripts/` : Scripts para modificação e launch
- `src/` : Código fonte do app (ex: Kotlin/Java para Android)
- `docs/` : Documentação

## Como usar
1. Clone o repo
2. Configure FFlags
3. Use o launcher para injetar e abrir Roblox.
